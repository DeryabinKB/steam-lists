# Steam Lists

Списки игр Steam, удобнее родных коллекций:
- перенос игры между списками одним действием (а не «добавил тут, удалил там»), копия — с Ctrl;
- свой порядок игр внутри списка (перетаскиванием или «В начало / В конец»);
- фильтры: текст, теги, жанры, часы, ачивки;
- работает на ПК и телефоне, списки синхронизируются через твой приватный репо на GitHub.

Приложение: https://deryabinkb.github.io/steam-lists/

## Как устроено
- **Этот репо** — только код. Никаких данных и ключей.
- **Твой приватный репо данных** (например `steam-lists-data`) — твои `lists.json`, `library.json`, `steam-collections.json`. У каждого пользователя свой.
- **`tools/steam-sync.ps1`** — мост со Steam на ПК. Читает библиотеку и коллекции, кладёт в репо данных; с `-Export` пишет списки обратно в коллекции Steam.
- Пароль Steam нигде не нужен. Токен GitHub и ключ Steam API хранятся только у тебя: в браузере (localStorage) и в `%APPDATA%\steam-lists\config.json` (зашифрованы Windows DPAPI).

## Начало работы
1. Создай пустой **приватный** репо для данных, например `steam-lists-data`.
2. Токен: github.com/settings/personal-access-tokens/new → Only select repositories → только репо данных → Permissions: **Contents: Read and write**.
3. Открой приложение → ⚙ → репо `логин/steam-lists-data` и токен.
4. На ПК скачай папку `tools` (или весь репо: Code → Download ZIP), запусти `sync.cmd`. В первый раз спросит репо, токен и (необязательно) ключ Steam API.
   - С ключом (steamcommunity.com/dev/apikey): вся библиотека + ачивки.
   - Без ключа или при закрытом профиле: только сыгранные, установленные и игры из коллекций.
5. В приложении ⚙ → «Импорт коллекций Steam» — твои коллекции станут списками.
6. Чтобы записать списки в Steam: **закрой Steam**, запусти `export-to-steam.cmd`. Перед записью делается бэкап (`%APPDATA%\steam-lists\backup`). Экспериментально: если Steam откатит изменения из облака — напиши в issues.

## Поиск
`текст` · `tag:RPG` · `genre:Action` · `h>10` (часов) · `ach<100` (% ачивок) · `played` · `new` (не запускал). Можно комбинировать. Теги сверху кликабельны.

## Разработка
Чистые HTML/CSS/JS без сборки: `index.html`, `style.css`, `app.js`. Пушишь в `main` — через минуту обновляется на GitHub Pages.
