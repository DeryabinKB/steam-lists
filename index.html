Настройки

Хранятся только в этом браузере. В коде и в репозитории их нет.

Создать: github.com/settings/personal-access-tokens/new → Only select repositories → твой репо данных → Contents: Read and write.

Как пользоваться

Настройка (один раз)

  1. Репо для данных. На GitHub: «+» → New repository → имя steam-lists-data, Private → Create. Там будут твои списки и библиотека.
  2. Токен. github.com/settings/personal-access-tokens/new → Expiration: год → Repository access: Only select → только репо данных → Permissions: Contents — Read and write → Generate. Сохрани в менеджер паролей. Никому не отправляй.
  3. Приложение. ⚙ → репо логин/steam-lists-data + токен → Сохранить. На каждом устройстве (ПК, телефон) один раз.
  4. Библиотека Steam. На ПК: скачать ZIP → распаковать → папка tools → sync.cmd. Спросит репо, тот же токен и ключ Steam API (необязательно, Enter — пропустить).
  5. Коллекции Steam → списки. ⚙ → «Импорт коллекций Steam».

Ключ Steam API — нужен ли

Без ключа скрипт видит только игры, которые ты запускал, установленные и из коллекций. С ключом — всю библиотеку и ачивки. Ключ: steamcommunity.com/dev/apikey (домен — любой, например localhost). Ключ остаётся только на твоём ПК, зашифрованным. Пароль Steam не нужен нигде.

Списки

  • Слева: «Вся библиотека», «Без списка» (ещё не разобранные) и твои списки. ✎ — переименовать, ▲ — поднять выше, ✕ — удалить (игры не пропадут).
  • Выделение: клик по игре; Shift+клик — диапазон; «Выделить все» — всё, что сейчас видно по фильтру.
  • Перенос: перетащи выделенное на список слева, или «Переместить в…». Игра уходит из текущего списка (из «Вся библиотека» — из всех списков). С Ctrl или «Копировать в…» — остаётся и там, и там.
  • Порядок: в списке с сортировкой «Мой порядок» перетаскивай игры или жми «↑ В начало / ↓ В конец».
  • Телефон: ☰ — списки; перетаскивания нет, выделяй и жми «Переместить в…».
  • ▶ — запустить игру в Steam.

Поиск

witcher — по названию · tag:RPG · genre:Экшен · h>10 — больше 10 часов · ach<100 — ачивки не все · played / new — запускал / не запускал. Можно сочетать: tag:coop new. Теги под поиском кликабельны.

Синхронизация

  • Списки сохраняются сами через пару секунд (справа сверху «✓ сохранено») в твой репо данных. На другом устройстве обновятся при открытии.
  • Библиотека (часы, ачивки, новые игры) обновляется, когда запускаешь sync.cmd на ПК.
  • В Steam: закрой Steam (трей → Выход) → export-to-steam.cmd. Списки станут коллекциями Steam. Перед этим делается бэкап. Порядок игр Steam не хранит.
  • Бэкап списков в файл: ⚙ → «Скачать бэкап списков». Плюс вся история изменений есть в репо данных на GitHub.
