Настройки

Хранятся только в этом браузере. В коде и в репозитории их нет.

Создать: github.com/settings/personal-access-tokens/new → Only select repositories → твой репо данных → Contents: Read and write.

Как поставить Worker — в «?» → «Обновление без ПК».

Наведи камеру телефона и открой ссылку. В QR твой токен: никому не показывай и не фоткай.

Как пользоваться

Настройка (один раз)

  1. Репо для данных. На GitHub: «+» → New repository → имя steam-lists-data, Private → Create. Там будут твои списки и библиотека.
  2. Токен. github.com/settings/personal-access-tokens/new → Expiration: год → Repository access: Only select → только репо данных → Permissions: Contents — Read and write → Generate. Сохрани в менеджер паролей. Никому не отправляй.
  3. Приложение. ⚙ → репо логин/steam-lists-data + токен → Сохранить. На каждом устройстве (ПК, телефон) один раз.
  4. Библиотека Steam. На ПК: скачать ZIP → распаковать → папка tools → sync.cmd. Спросит репо, тот же токен и ключ Steam API (необязательно, Enter — пропустить).
  5. Коллекции Steam → списки. ⚙ → «Импорт коллекций Steam».

Как открывать быстро

  • ПК: в папке программы (где tools) лежит ярлык «Steam Lists» — после первого sync.cmd он получит иконку. Ещё удобнее: в Chrome/Edge справа в адресной строке значок «Установить приложение» (⊕ или экран со стрелкой) — откроется отдельным окном без вкладок, его можно закрепить на панели задач.
  • Телефон: меню браузера → «Добавить на главный экран» / «Установить приложение».

Ключ Steam API — нужен ли

Без ключа скрипт видит только игры, которые ты запускал, установленные и из коллекций. С ключом — всю библиотеку и ачивки. Ключ: steamcommunity.com/dev/apikey (домен — любой, например localhost). Ключ остаётся только на твоём ПК, зашифрованным. Пароль Steam не нужен нигде.

Списки

  • Слева: «Вся библиотека», «Без списка» (ещё не разобранные) и твои списки. ✎ — переименовать, ▲ — поднять выше, ✕ — удалить (игры не пропадут).
  • Выделение: клик по игре; Shift+клик — диапазон; «Выделить все» — всё, что сейчас видно по фильтру.
  • Перенос: перетащи выделенное на список слева, или «Переместить в…». Игра уходит из текущего списка (из «Вся библиотека» — из всех списков). С Ctrl или «Копировать в…» — остаётся и там, и там.
  • Порядок: в списке с сортировкой «Мой порядок» перетаскивай игры или жми «↑ В начало / ↓ В конец».
  • Телефон: ☰ — списки; перетаскивания нет, выделяй и жми «Переместить в…».
  • ▶ — запустить игру в Steam.
  • ⓘ, двойной клик или клик по ачивкам — карточка игры: описание, ссылки (магазин, гайды, SteamDB, сколько проходить), в какие списки входит, и все достижения с иконками, редкостью (% игроков) и датой получения.
  • 🎯 Цели: в карточке жми 📌 у ачивки — она появится в «Цели» слева. Полученные отмечаются ✓ после обновления (⟳ или sync.cmd).
  • Прогресс ачивок (34/100) — где игра его отдаёт. Связь «счётчик → ачивка» берётся из файлов Steam на ПК, поэтому прогресс появляется после sync.cmd и только для игр, запускавшихся на этом ПК. Дальше цифры обновляет и ⟳. Сортировка «Ближе к получению».
  • ⚡ Умные списки — сохранённый поиск, обновляются сами. Набери фильтр в поиске (и/или выбери теги) → слева «⚡ Умный список из поиска». ✎ — поменять название и фильтр. Вручную игры в них не кладутся, и в Steam они не выгружаются.

Поиск

witcher — по названию · tag:RPG · genre:Экшен · h>10 — больше 10 часов · ach<100 — ачивки не все · played / new — запускал / не запускал. Можно сочетать: tag:coop new. Теги под поиском кликабельны.

Обновление без ПК (⟳)

Приложение само делает ⟳ при открытии, если с прошлого обновления прошло больше часа. Кнопка ⟳ сверху обновляет библиотеку, часы и ачивки прямо из приложения, хоть с телефона. Steam не пускает браузер к своему API, поэтому нужна бесплатная прокладка Cloudflare Worker (один раз, ~5 минут):

  1. dash.cloudflare.com (регистрация бесплатная) → Workers & Pages → Create → Worker → имя steam-lists → Deploy.
  2. Edit code → удали всё → вставь код из tools/worker.js (кнопка «Copy raw file») → Deploy.
  3. Worker → Settings → Variables and Secrets → Add, тип Secret: STEAM_KEY = ключ Steam API; ещё один ACCESS = пароль (⚙ → «🎲 Придумать пароль»). Deploy.
  4. В ⚙ приложения: адрес Worker (виден на его странице, https://….workers.dev) и тот же пароль → Сохранить.

Ключ Steam хранится только в Cloudflare, в приложение он не попадает. Без пароля Worker ничего не отдаёт. Первый раз ⟳ идёт долго (~1 сек на игру, держи вкладку открытой), дальше — только новые и сыгранные игры. Коллекции Steam читать и записывать по-прежнему может только ПК (sync.cmd / «💾 В Steam»).

Синхронизация

  • Списки сохраняются сами через пару секунд (справа сверху «✓ сохранено») в твой репо данных. На другом устройстве обновятся при открытии.
  • Библиотека (часы, ачивки, новые игры) обновляется, когда запускаешь sync.cmd на ПК.
  • 💾 В Steam (только на ПК): сохраняет списки и открывает окно выгрузки — оно само закроет Steam, запишет коллекции и запустит Steam снова. Перед записью бэкап. Кнопка заработает после одного запуска sync.cmd новой версии; браузер спросит «Открыть приложение?» — разреши. Порядок игр Steam не хранит. Пока экспериментально.
  • 🖥 С ПК (сверху, только на ПК) — то же, что запустить sync.cmd: забирает коллекции Steam, библиотеку и прогресс ачивок. Работает после одного ручного запуска sync.cmd.
  • Бэкап списков в файл: ⚙ → «Скачать бэкап списков». Плюс вся история изменений есть в репо данных на GitHub.
